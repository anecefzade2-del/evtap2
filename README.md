# Calculator - C# Windows Forms

Şəkildəki dizaynın C# Windows Forms ilə hazırlanmış kalkulyator layihəsi.

## Xüsusiyyətlər
- Number one / Number two daxiletmə
- Command (`+`, `-`, `*`, `/`) seçimi
- Result ilə hesablama, Answer-də göstərmə
- Clear ilə sıfırlama

## İşə salmaq
```powershell
dotnet run --project CalculatorApp.csproj
```
